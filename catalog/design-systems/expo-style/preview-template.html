tokens / surfaces / five steps

Canvas through dark, one inversion at the floor.

The brand rotates through canvas → soft → card → strong → dark, with the dark step reserved for code surfaces and the featured pricing tier. The dark surface is scarce by design — using it twice in a row breaks the brand's pacing.

01 / canvas --background page floor · editorial body
02 / soft --brand-canvas-soft alternating band · macOS chrome
03 / card --card feature card · workflow step
04 / strong --brand-surface-strong badges · ecosystem tiles · pill fills
05 / dark --brand-surface-dark code blocks · featured tier · scarce voltage

tokens / cards / workflow

From commit to QR code, in one channel.

The brand's documented workflow card carries a 32px square icon plate, a step number, a title, and a body paragraph. The same three-card row narrates how Halcyon's mobile team takes a sprint from local edit to a QR code in a reviewer's chat.

01 step / write

Edit locally with hot reload.

The team runs the dev client on a teammate's phone over the office Wi-Fi. Saves land in under a second. Native modules rebuild on the next commit, not the next file save.

02 step / build

Ship to the build channel on push.

Every push to main fans out to iOS and Android channels. The build dashboard shows the queue, the median duration, and the last reviewer who approved the merge.

03 step / review

Send a QR code, get device QA back.

Reviewers scan the build's QR code in Slack and run it on their daily phone. Feedback lands as a thread on the commit, not as a slide deck two days after the merge.

pricing

Three shapes, one inversion at the middle.

The featured tier flips to the documented dark surface — colour-block contrast does the elevation work. No accent borders, no scale shifts, no badge. Just inversion.

tokens / type + components

Inter at the action layer, JetBrains Mono on every code surface.

The brand pairs Inter at modest weights — display 600, body 400 — with JetBrains Mono on every code surface. Display tracks negative across the whole scale. Body never bolds. No custom display family; the brand trusts Inter's editorial neutrality.
