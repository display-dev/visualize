Tokens · Typography

Mona Sans, semibold heads, mono for code.

Six roles drive the surface. Headings sit at semibold 600 with tight negative tracking; body holds at 400. Mono code is ui-monospace at thirteen pixels — the inline pill at the same scale as the surrounding prose.

Note

The verified-domain check runs before session bootstrap. If the invite email domain doesn't match an org's verified set, the request fails with domain_not_verified.

Tip

Run npm run seed to rebuild the local fixtures. Sprint personas land in a known-good shape; no manual re-clicking through onboarding to get to a representative state.

Important

Schema changes ship as ordered migrations. CI runs the full set against an ephemeral container so the production deploy applies the same diff every time.

Warning

Don't bypass the auth adapter to "fix" theoretical race conditions. The windows are milliseconds wide on single-admin operations; raw SQL replaces a tradeoff with worse code.

Caution

Wrap every scheduled job with withLeaseLock. Bare cron handlers fire on every replica when the app runs more than one instance.
