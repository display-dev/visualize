Engineering / Multi-tenant provisioning

Multi-tenant provisioning

Every Halcyon customer gets a tenant created at signup. The provisioning service writes the row to tenants, allocates a slug, and emits a tenant.created event the rest of the platform listens for.

Provisioning is idempotent

Calling createTenant with the same external id twice returns the existing row instead of erroring. The retry-safe contract is the reason webhooks don't need processing leases at the boundary.

Endpoint

POST /v1/tenants 
// Provision a tenant from a Halcyon signup webhook.
const tenant = await halcyon.tenants.create({
  externalId: 'usr_8f2c4d',
  slug: 'morgan-lee',
  region: 'us-east-1',
  plan: 'team',
});
console.log(tenant.id); // → 'tnt_01HQ3...'

Parameters

externalId string Required

The caller's stable identifier for the tenant. Halcyon uses this to deduplicate retries from the signup webhook; passing the same value twice returns the existing row.

region "us-east-1" | "eu-west-1"

Data-residency region. Defaults to us-east-1 when omitted; the team typically lets new customers default and migrates region-locked accounts on request.

plan string

Plan slug at provisioning time. Halcyon's billing layer reconciles this against the active subscription on the next event; mismatches are not fatal here.

tokens / surfaces / five steps

Canvas through dark, one inversion at the floor.

The brand rotates through canvas → surface → card → hairline → canvas-dark. The hairline step is a 2px border on canvas, not a tinted fill — Mintlify's docs grid uses the hairline as separation, not a soft surface. The dark step is scarce: code wrapper, promo strip, and the featured pricing tier when it ships inverted.

01 / canvas --background page floor · prose body
02 / surface --brand-surface code-inline tint · sidebar active fill
03 / card --card docs frame · pricing tier · faq accordion
04 / hairline --border grid separation · prop-row dividers
05 / dark --brand-canvas-dark code wrapper · promo strip · scarce voltage

tokens / type + components

Inter for the page, Geist Mono on every code surface.

Display tracks negative across the whole scale (−3% on the hero, −2.5% on h2). Body never bolds. Geist Mono carries inline code, type signatures, property names, and the page-level code block. The pairing is the brand's developer-respect signal.
