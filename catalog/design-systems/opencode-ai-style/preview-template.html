how halcyon ships

Diffs proposed, tests run, humans sign off.

Halcyon's engineering team treats the coding agent as a junior pair. The agent owns the keyboard during exploration; the human owns the merge button. Every change goes through the same loop.

[+] Working tree as the input. The agent reads the repo the same way the engineer does — files, not a vector index. No retrieval to drift, no rebuilt context per session.
[+] Tests as the proof. Every diff is followed by a test run before the agent claims the change works. The exit code is the source of truth, not the chat reply.
[+] Plan mode for the hairy ones. The agent writes the plan first, the engineer reads it, then the diff lands. Cuts the time spent reverting speculative refactors to roughly zero.
[+] One scrollback per branch. The session is the record. Avery Park reviews Sam Walker's session log before the merge — the conversation is the design doc.
[x] No background autopilot. The agent does not commit, push, or open PRs on its own. Every external action waits behind a keystroke.
