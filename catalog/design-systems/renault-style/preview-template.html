Tokens · Type + components

One typeface, two weights.

NouvelR runs the entire hierarchy — display, heading, body, captions, button labels. Two-weight contrast — 400 body, 700 display — carries the brand. Display sizes clamp to a 0.95 line-height so multi-line headlines stack confidently.
