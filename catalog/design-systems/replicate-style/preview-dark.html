tokens · surface

Five surfaces, one ladder.

Canvas as the page floor. Bone as the section divider. Card as the white plate every model lives on. Dark and deep are the print-pull-quote surfaces that host code wells and the global footer. Surfaces never modulate by elevation shadow — colour-blocking carries the rhythm.

0 --background cream canvas · default page
1 --brand-surface-bone inset band · feature group
2 --card white plate · model + input
3 --brand-surface-dark code well · featured tier
4 --brand-surface-deep footer · tab strip

how it works

Two calls, one response.

The print-pull-quote band hosts a code well in JetBrains Mono. The dark surface inverts the page rhythm without breaking the cream ladder around it. Halcyon's platform team wraps a single helper around the generic inference call; the rest of the engineering team treats it as a function.

# Generic inference call. Model identifier is a placeholder.import halcyon_inference as hiclient = hi.Client(api_key=os.environ["HALCYON_API_KEY"])job = client.run(  model="halcyon-labs/image-gen-xl",  input={"prompt": "a quiet workshop at dusk"},)# Returns a stable URL the engineering team archives.print(job.output[0])
