# Warm Industrial

A design system with warm gray surfaces, charcoal sections, electric-blue
accents, and a mix of heavy sans-serif and italic serif display type.

## Preview and reference

- [Light preview](preview.html)
- [Dark preview](preview-dark.html)
- [Design guidance](DESIGN.md): suitability, visual identity, typography, and component guidance.
- [Tokens](tokens.css): concrete values and theme treatments.

Previews demonstrate the system; their content and layouts are examples.

## Theme usage

> Apply the Warm Industrial reference (`warm-industrial`) to this artifact. Replace the
> project's visual styling for this artifact only; keep its logo, content,
> section order, and behavior.

Follow Visualize's [shared theme workflow](../../SKILL.md#artifact-themes)
for application, project constraints, explicit overrides, and comparisons.
For project-wide capture or derivation, use [teach](../../reference/teach.md).
