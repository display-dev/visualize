Tokens · Surfaces · Five steps

White through dark, one inversion at the floor.

Pages rotate through canvas → secondary → card → strong → dark, with the dark step reserved for the footer and the featured pricing tier. The dark surface is scarce by design; using it twice in a row breaks the brand's pacing.

01 · Canvas --background page floor · editorial body
02 · Secondary --secondary nav-pill-group · soft section dividers
03 · Card --card feature cards · testimonial cards
04 · Strong --brand-surface-strong hairline alternative · disabled fills
05 · Dark --brand-surface-dark footer · featured tier · scarce voltage

Tokens · Type + components

Geometric display, neutral body.

Display headlines run Inter 600 with -0.04em tracking (an Inter approximation of the documented Cal Sans face). Body type stays Inter 400, never bolder. The boundary doesn't blur — every display headline carries the same weight-and-tracking signature.
