# Editorial

A design system for long-form publishing, with warm cream surfaces,
serif headings, and restrained navy emphasis.

## Preview and reference

- [Light preview](preview.html)
- [Dark preview](preview-dark.html)
- [Design guidance](DESIGN.md): suitability, visual identity, typography,
  components, and design rules.
- [Tokens](tokens.css): concrete values and light/dark treatments.

Previews demonstrate the system; their content and layouts are examples.

## Theme usage

Use Editorial as an artifact theme when creating an artifact, restyling
an existing one, or comparing design directions.

Example request:

> Apply Editorial to this report. Replace the project's visual styling
> for this artifact only; keep its logo, content, section order, and behavior.

The theme uses this package's design guidance and tokens together.
Its application can affect typography, color, spacing, and component
treatment; it is not limited to swapping palette and font values.

Follow Visualize's [shared workflow](../../SKILL.md#artifact-themes) for project
constraints, explicit overrides, exploration, and verification.

For project-wide capture or derivation, use [teach](../../reference/teach.md).
