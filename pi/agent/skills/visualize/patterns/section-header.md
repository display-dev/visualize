# Section Header

## Use when

Use section-header guidance when an artifact has many sections, mixed density, or recurring labels that need a clear hierarchy.

## Do not use when

Do not add decorative icon tiles or eyebrows to every heading. Plain headings are often stronger.

## Type roles

Eyebrows classify; headings state the idea; subheads explain scope. Keep labels smaller than headings and avoid uppercase body text.

## Spacing and borders

Section gaps should be larger than subsection gaps. A single accent rule can help, but repeated ornamental markers create noise.

## Mobile behavior

Reduce display scale before wrapping every heading to three lines. Preserve the section sequence and avoid sticky labels unless navigation is load-bearing.

## Failure modes

- Every heading receives the same icon tile.
- Eyebrow, heading, and subhead all compete.
- Dense reports use hero-scale headings inside every section.
