# Source List

## Use when

Use source lists when evidence provenance affects trust, recency, or reproducibility.

## Do not use when

Do not create fake citations, placeholder sources, or ornamental source entries for common knowledge.

## Semantic shape

Use ordered lists for footnotes, unordered lists for grouped sources, and links with visible titles. Include publisher/date when recency matters.

## Type roles

Source titles should be readable. URLs and access details are secondary. Keep footnote numbers calm and consistent.

## Mobile behavior

Long URLs break safely. Source entries stack without oversized chrome.

## Failure modes

- Fabricated citations.
- URL-only source lists with no title or context.
- Source entries louder than the claims they support.
