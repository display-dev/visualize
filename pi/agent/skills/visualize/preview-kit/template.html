Components

Buttons, alerts, badges, cards, table — the vendored shadcn-html surface rendered against this design system's tokens.

Primary Secondary Destructive Outline small small outline

Default card

Standard surface — card, border, padding, gap.

Cards inherit --card + --card-foreground and stack content with the design system's spacing rhythm.

Elevated card

Shadow over surface, no border.

Uses --shadow-* scale. Lifts off the page; suits floating CTAs or modal previews.

Interactive card

Hover + focus state — keyboard reachable.

Hover swaps to --accent + --accent-foreground. Focus ring uses --ring.

Heads up

An informational alert. Uses surface and foreground tokens; no semantic colour.

Something went wrong

A destructive alert. Borders and text take --destructive.

Prose & code

Prose hierarchy and code rendering. The body inherits --font-sans; code.inline + .code-block render in --font-mono.

Subheading at title scale

Hover a link to confirm link colour resolves to --primary. Inline code such as getComputedStyle(root) picks up the muted background.
