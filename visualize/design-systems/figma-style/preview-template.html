Halcyon · workspace

A canvas for the whole team to think on.

Halcyon's product team writes notes, sketches reviews, and edits together on a single editorial canvas — monochrome chrome around the work, pastel blocks between the chapters.

Color block · Lime

Sticky-note rhythm, sized up.

Each color-block section spans the full canvas — like a designer arranging giant sticky notes on a clean wall. Lime is the first chapter break, the place where the monochrome paper-chrome stops carrying the page and a block of color takes over.

Why the color blocks work

The blocks read as intentional rather than decorative because the monochrome chrome around them is rigorously plain. White paper makes the color feel chosen.

Tokens · Color blocks

Seven pastel blocks, plus monochrome chrome.

The narrative palette: lime, lilac, cream, pink, mint, coral, navy — each block spans a full section, never tucked into a card. Below: the monochrome chrome tokens that frame everything.

Color block · Lilac

One pill shape, in two colours.

Every CTA is a 50 px pill. Filled black on light surfaces, filled white on dark surfaces. No outlined buttons in the marketing chrome, no rounded-square variants — the radius is the same anywhere a button appears.

Color block · Navy

The deep block at the close.

Navy is the only dark block in the system — used once per page, typically as the closing chapter before the footer. The chrome inverts: white type, white pill, the same plain rhythm in a different polarity.

Used sparingly

The pastel blocks rotate freely across long-form pages, but navy appears once. Repeating it would flatten the contrast that makes a single dark block read as a section divider rather than a theme.
