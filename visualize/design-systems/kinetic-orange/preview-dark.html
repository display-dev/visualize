/ Tokens · Colour

Three colours. No exceptions.

Kinetic Orange carries the hero. Solid Black runs every divider and the marquee canvas. Pure White is the page floor and the inverted ink on dark surfaces. There are no documented secondary brand colours — every accent is one of these three at a different polarity.

/ Tokens · Surfaces

Three canvases. Sharp transitions.

The system cycles polarity within a single layout. White is the page floor; orange is the headline ground; black is the marquee + service-list ground. No mid-tones, no glass, no gradients.

/ Light --brand-canvas-light page floor · CTA · footer · type demos
/ Orange --brand-canvas-orange hero · brand mark · primary signal
/ Night --brand-canvas-night marquee · service list · pill nav

/ Tokens · Type

Archivo Black. Space Mono. Inter.

Archivo Black runs every uppercase display surface, tracked tight at -0.04em with a 0.85 line-height. Space Mono runs metadata, nav links, captions, and code chrome. Inter handles body prose only — no headlines, no chrome.

/ Tokens · Components

Pill chrome. Sharp everything else.

Pill-shaped buttons + nav + tags are the only rounded surfaces. Every other edge is a 2px solid black hairline. Hover transforms run on a 200ms ease-out curve; reduced-motion environments collapse them to instant.
